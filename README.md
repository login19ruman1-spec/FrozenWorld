# FrozenWorld — Вечная зима

Плагин для **Paper 1.21.4 / Java 21**. Проект находится в активной разработке.

## Уже реализовано
- Команда `/frozenworld` (алиасы `/fw`, `/зима`) и русскоязычное GUI.
- Переключение режима зимы из меню.
- Остановка/возобновление смены времени суток с сохранением прежнего gamerule для загруженных миров.
- Включение и отключение снегопада/накопления снега.
- Настройка количества слоёв снега в меню.
- Основные параметры вынесены в `config.yml`.

## Сборка
Требуется JDK 21 и Gradle:

```bash
gradle build
```

Готовый JAR появится в `build/libs/`.

## Установка
1. Соберите проект.
2. Поместите JAR из `build/libs/` в папку `plugins` сервера Paper 1.21.4.
3. Запустите сервер и выдайте себе право `frozenworld.admin` (по умолчанию оно есть у операторов).
4. Выполните `/frozenworld`.
